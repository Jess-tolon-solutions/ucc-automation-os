## Worker changes deployed

### Immediate response pattern
- GET `/r/:lead_id` and `/reroute` return HTML confirmation instantly
- All cascade work (BD calls, matching, GHL callback) runs in `ctx.waitUntil()`
- Avoids Cloudflare free tier CPU timeout (Error 1102)

### Bounding box pre-filter
- Filters members to ±1° lat/lng box before haversine calculations
- Reduces per-request work from 1,048 members to ~20-50
- Constant `BBOX_PADDING_DEG = 1.0` (~70 miles, safely > 50 mile radius)

### Timeouts on all outbound fetches
- BD API calls: 10 second timeout
- GHL webhook callbacks: 10 second timeout
- Doctor notice POSTs: 10 second timeout
- Logged failures instead of hanging indefinitely

### KV cache changes
- Request path reads KV cache ONLY — never crawls BD inline
- If cache empty, returns error callback to GHL instead of blocking
- TTL extended to 25 hours (overlaps daily cron)

### Cache management endpoints
- `POST /cache/rebuild` — manual cache population
- `GET /cache/status` — check if cache exists and member count

### Scheduled cron trigger
- Runs daily at 3am UTC
- Rebuilds member cache from BD API
- Configured in `wrangler.toml`: `crons = ["0 3 * * *"]`

### Level 2+ only matching
- Cascade now matches only Level 2+ doctors (plans 2, 18, 19, 23, 26, 27, 29, 33)
- Annual/Unverified (plans 3, 31) excluded from cascade
- `has_level2` is always `true` when `status: matched`

### Doctor notice POST includes first_name
- Body: `{"email": "...", "first_name": "...", "lead_id": "..."}`
- Empty string if member has no first name
